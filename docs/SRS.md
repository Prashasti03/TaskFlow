# Software Requirements Specification

## Project Name

TaskFlow – Project Management & Issue Tracking System

## 1. Introduction

### 1.1 Purpose

TaskFlow is a web-based project management and issue tracking system designed to help teams manage projects, team members, tasks, issues, sprints and project progress.

### 1.2 Scope

The system will provide:

- User authentication
- Role-based authorization
- User management
- Project management
- Team management
- Task management
- Issue tracking
- Sprint management
- Comments
- Notifications
- Dashboard
- Reports

## 2. Technology Stack

### Backend

- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate

### Frontend

- ReactJS
- Vite
- Bootstrap

### Database

- MySQL

## 3. User Roles

- Admin
- Project Manager
- Developer
- Tester / QA
- Viewer / Stakeholder

Requirements will be documented module-by-module as development progresses.
