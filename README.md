# TaskFlow – Project Management & Issue Tracking System

TaskFlow is a full-stack project management and issue tracking system inspired by tools such as Jira.

The application is designed to help teams manage projects, team members, tasks, issues, sprints, comments, and project progress from a centralized platform.

## 🚀 Project Status

**Current Phase:** Phase 0 – Project Setup

**Current Module:** Project Foundation
